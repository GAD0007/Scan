# Chopfast

A React restaurant landing-page starter built with Vite. The page currently includes a responsive home hero, sample menu, restaurant intro, and visit footer. Menu copy and prices are sample content—replace them with your restaurant's details.

## Start developing

Install packages with `npm install`, then start the local Vite server with `npm run dev`. Open the local address printed in the terminal.

## Build

Run `npm run build` to create a production build. Use `npm run preview` to preview that build locally.

## Main files

- `src/App.jsx` — page sections and sample menu data.
- `src/styles.css` — layout, colors, responsive styles, and bowl illustration.
- `src/main.jsx` — React entry point.
